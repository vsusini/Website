# Profile Website

## Overview
This repository contains the source code for my personal profile/resume website, built with React and Vite. It showcases my professional experience, skills, and projects using a responsive and interactive design. The live version of this website is deployed at [vsusini.com](https://vsusini.com).

## Technologies Used
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/) (for fast development and build)
- CSS3 (including media queries for responsiveness)
- [react-awesome-reveal](https://github.com/dennismorello/react-awesome-reveal) for scroll animations

## Features
- Responsive design for desktop and mobile views
- Animated sections and interactive hover effects
- Sections for work experience, education, skills, and projects
- Social media links and contact information
- Custom fonts and gradient background

## Structure
- `src/`
  - `App.tsx`: Main React component
  - `components/`: Reusable React components (e.g., `Bubble`, `Footer`, `SkillsSection`, `TitleSection`)
  - `index.css`: Combined and responsive CSS for the entire site
- `public/`: Images and font files
- `index.html`: Main HTML entry point
- `vite.config.ts`: Vite configuration
